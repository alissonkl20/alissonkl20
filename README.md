## Sobre mim

Desenvolvedor Full Stack com foco em **backend**, construindo APIs, sistemas web e regras de negócio
com **Python/Django** e **PHP/Laravel**. No frontend, trabalho com **Next.js**, e na camada de dados
com **MySQL** e **PostgreSQL**.

- Desenvolvimento de **APIs REST** e aplicações web completas
- Modelagem de dados e otimização de consultas em bancos relacionais
- Código organizado, testável e de fácil manutenção
